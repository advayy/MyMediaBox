# Third-party attribution

## TMDB

MyMediaBox uses The Movie Database (TMDB) API for media metadata and images when a TMDB token is configured.

The app displays the required notice:

> This product uses the TMDB API but is not endorsed or certified by TMDB.

Before distributing a public TMDB-enabled build, add one of TMDB's approved, unmodified logo assets to the in-app Credits area. The logo is not committed here so the project does not redistribute an unofficial or stale copy.

TMDB attribution reference: https://developer.themoviedb.org/docs/faq

## JustWatch

Streaming availability shown by MyMediaBox is supplied by JustWatch through TMDB. The detail page keeps visible JustWatch attribution alongside provider data.

## 98.css

The Retro 98 skin uses 98.css by Jordan Scales, an MIT-licensed CSS design system for recreating Windows 98-style interfaces.
